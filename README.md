# ☕ ИС «Кафе-Заказ» (Студенческий проект)

Информационная система для учёта заказов в кафе. Предназначена для автоматизации приёма заказов, передачи их на кухню, учёта оплаты и формирования отчётности.

## 🚀 Возможности

- **Официант:** создание заказов, отправка на кухню, приём оплаты.
- **Повар:** просмотр заказов, отметка о готовности блюд.
- **Администратор:** управление пользователями, меню, столиками, отчёты по выручке.

## 🛠️ Технологии

- **Backend:** PHP 8.1+
- **База данных:** MySQL 8.0
- **Frontend:** HTML5, CSS3, JavaScript (ES6)
- **Веб-сервер:** Apache (OpenServer/XAMPP)

## 📋 Требования

- PHP 8.0 или выше
- MySQL 5.7 или выше
- Любой веб-сервер (Apache/Nginx)
